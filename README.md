# PROFACE Workflow Studio — Demo V4 (Blank Start)

## ทดลองใช้

1. แตก ZIP แล้วเปิด `index.html` ด้วย Chrome, Safari หรือ Edge; สามารถนำ `index.html`, `app.js`, `styles.css` ขึ้น GitHub Pages ได้ทั้งชุด
2. หน้าเริ่มต้นไม่มีงาน/สินค้า/ราคา/รูปถ่ายตัวอย่าง
3. กด **สร้างโปรเจกต์** เลือกเซลล์เจ้าของงาน: `S'Beam`, `S'Tong`, `S'Gun`, `S'Bank`, `Showroom` (จำเป็น)
4. ฝั่ง **วัดหน้างาน** กรอกชั้น ห้อง ขนาด ชนิดม่าน แนบรูปภาพของแต่ละชุด และกดบันทึก
5. ฝั่ง **คำนวณราคา** แอดมินเลือกวิธีวางผ้าแบบ 1 ใน 3 และกรอก หน้าผ้า / ราคาราง / ราคาตั้ง -50% *แต่ละชุด*
6. ฝั่ง **ตรวจสอบงาน** ตรวจรูปภาพของทุกชุดและราคาก่อนยืนยัน
7. ฝั่ง **ใบสั่งงาน** ตรวจเอกสารและเลือก Print / Save PDF
8. ฝั่ง **งานของเซลล์** เลือกชื่อเซลล์เพื่อดูงานของตนย้อนหลังในเครื่องเดียวกัน, เปิดโปรเจกต์ที่บันทึกไว้ หรือ Export CSV สำหรับนำเข้า Google Sheets
9. เริ่มโปรเจกต์ใหม่ด้วย **+ งานใหม่** (เก็บโปรเจกต์ก่อนหน้าไว้ในประวัติ) หากต้องการล้างทั้งหมดใช้ **ล้างข้อมูลทดลองทั้งหมด**

## สูตร V4 และเกณฑ์หน้าผ้า

เปิดให้คำนวณราคาของ **ม่านลอน / Wave** โดยอ้างอิงสูตรจากไฟล์ Excel ตัวอย่างที่ให้มา ส่วนม่านจีบและม่านตาไก่ให้กรอกข้อมูลได้ แต่ยังไม่ออกราคาจนกว่าจะได้รับและยืนยันสูตรจริงของแต่ละชนิด โปรดอ่าน `FORMULA_RULES.md`

- **หน้ากว้าง**: ความกว้างชุดม่านต้องไม่เกินหน้าผ้า − 0.30 ม. ความสูงไม่จำกัดด้วยหน้าผ้า
- **หน้าแคบ**: เมื่อกว้างเกินหน้าผ้าต้องแจ้งเรื่องรอยต่อ ความสูงไม่ใช่ข้อจำกัดของการวางแนวผ้า (แต่มีผลต่อจำนวนผ้าคิดราคา)
- **หน้ากว้างเย็บกลับหน้าผ้า**: ความสูงชุดม่านต้องไม่เกินหน้าผ้า − 0.30 ม. ความกว้างไม่จำกัดด้วยหน้าผ้า
- ตัวคูณราคาใน V4 ยังอ้างอิง Excel งานม่านลอนเท่านั้น การคำนวณจำนวน **หน้า/ชิ้นเพื่อตีราคา** ไม่จำเป็นต้องเท่ากับจำนวน **ชิ้นสั่งผ้า/ผลิตจริง**
- ราคาปัดหลักร้อยตามข้อมูลตัวอย่าง แล้วบวก VAT 7%

## การเก็บข้อมูลและ Google Sheets

- V4 เป็น **Demo แบบใช้งานในเบราว์เซอร์เท่านั้น** ใช้ localStorage ไม่มีการสร้าง Google Sheets, ไม่ดึงข้อมูลจาก Sheets จริง, ไม่มีเซิร์ฟเวอร์ / Login จริง และไม่มีระบบเข้าถึงเฉพาะคนในจริง
- Dashboard แยกชื่อเซลล์ใช้งานได้จาก **ข้อมูล Demo ที่เก็บไว้บนเบราว์เซอร์เครื่องนั้น** ไม่แชร์ข้ามเครื่องหรือผู้ใช้งาน
- กด **Export Google Sheets CSV** จาก Dashboard เพื่อดาวน์โหลดรายการทุกโปรเจกต์พร้อมฟิลด์ `sales_owner` แล้วนำเข้า Sheets (File → Import)
- Export JSON มุมขวาบนจะมีข้อมูลการทำงานและรูปภาพแบบ data URL ในงานที่เปิดอยู่ + โปรเจกต์เก่า โปรดเก็บไฟล์อย่างปลอดภัย
- CSV จะมีเพียงจำนวนรูปแนบ ไม่บันทึกรูปลงชีต ภาพจริงต้องเก็บใน private object storage ที่มีกฎสิทธิ์ เช่น Firebase Storage / Google Cloud Storage และบันทึก `photo_id/photo_url` ที่ผู้ใช้มีสิทธิ์เปิดได้ในฐานข้อมูล
- ข้อมูลในเบราว์เซอร์มีข้อจำกัดพื้นที่เก็บ หากรูปมากอาจเต็มได้ ไม่เหมาะใช้เก็บงานบริษัทจริงและข้อมูลอาจหายเมื่อล้างข้อมูลเว็บ
- เมื่อติดตั้งจริงต้องใช้ Backend ตรวจ Google Identity Token และตรวจสิทธิ์ของผู้ใช้งานก่อนอ่าน/เขียน Sheets/ไฟล์รูป ไม่เก็บ key/token ของ Sheets ไว้ใน GitHub Pages
- เซลล์หนึ่งคนควรเห็นเฉพาะข้อมูลตนเองผ่าน Backend; Admin เห็นทุกโปรเจกต์ พร้อม Audit Log และ approval-lock

## ข้อจำกัดที่จงใจเว้นไว้ก่อน

- ยังไม่ได้ทำสูตรจำนวนผ้าที่ฝ่ายจัดซื้อสั่งจริง หรือสูตรใบสั่งช่างเย็บ/งานผลิต
- ราคาม่านจีบ/ม่านตาไก่/สินค้าอื่นยังไม่เปิดจนกว่าจะตรวจสูตรครบ
- สูตรเย็บกลับมี **สูตรราคาให้ผลเหมือนหน้าแคบตามตัวอย่าง Excel ที่ได้รับ** แต่ไม่ได้รับการยืนยันว่าทุกรหัสและทุกกรณีคิดราคาเหมือนกัน ห้ามนำไปใช้เสนอราคาจริงโดยไม่ตรวจสอบกับแอดมิน
- เลขที่งานและการสลับดูเซลล์เป็นระบบจำลอง ไม่ใช่การแสดงตัวตนจริง

## ข้อมูลตัวอย่างสำหรับตรวจสอบ

- Wave กว้าง 2.00 สูง 2.60 ม., หน้าผ้า 3.00 ม., ราคาราง 800, ราคาผ้า 295, วิธีหน้ากว้าง → ราคาขาย **4,100 บาท** (ตรงกับตัวอย่างไฟล์)
- ในกรณีข้างต้น: ถ้ากว้าง 2.80 ม. และวิธีหน้ากว้าง หน้าผ้า 3.00 ม. → **ไม่ผ่าน** เพราะ 2.80 > 2.70
- หากเปลี่ยนเป็นเย็บกลับ สูง 2.60 ม., หน้าผ้า 3.00 ม. → ผ่านข้อจำกัดแนวผ้า; แต่ถ้าสูง 2.90 ม. → **ไม่ผ่าน**
- หน้าแคบ กว้าง 6.00 ม. หน้าผ้า 1.50 ม. → แจ้งรอยต่อ; ตัวเลขพื้นที่อย่างคร่าว ๆ = 4 หน้า *ไม่ใช่* 4 ชิ้นสำหรับคำนวณราคาหรือสั่งผลิต เพราะสูตรราคา Wave มีตัวคูณจีบ/เผื่อเพิ่มเติม
