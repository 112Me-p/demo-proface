# PROFACE Workflow Studio — V5 (Blank Start)

เว็บ Demo สำหรับลอง Flow ของฝ่ายขาย/แอดมินตามข้อมูลบริษัท PROFACE เริ่มจากศูนย์ ไม่โหลดข้อมูลลูกค้าตัวอย่าง

## วิธีใช้งาน

1. แตกไฟล์ ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน แล้วเปิด `index.html` หรืออัปโหลด `index.html`, `app.js`, `styles.css`, `quote.css` บน GitHub Pages
2. สร้างโปรเจกต์: เลือกผู้รับผิดชอบ S'Beam / S'Tong / S'Gun / S'Bank / Showroom
3. วัดหน้างาน: เลือกม่านลอน / ม่านจีบ / ม่านตาไก่ กรอกขนาดและแนบรูป (รูปทุกชุดใช้ในจุดของตัวเอง)
4. ทำราคา: แอดมินเลือกหนึ่งในสามวิธีคำนวณผ้าสำหรับ **ม่านแต่ละชุด**, กรอกหน้าผ้า ราคาราง ราคาผ้า (ราคาตั้ง -50%)
5. ตรวจสอบ: เห็นชนิดม่านในแต่ละรายการ กดรับรองราคาและรูปก่อนออกเอกสาร
6. ใบสั่งงาน: พิมพ์ใบส่งต่อ และกด **สร้างใบเสนอราคา**
7. ใบเสนอราคา: ตรวจเลขเอกสาร วันที่ รายละเอียดลูกค้า ชื่อเซลล์ ส่วนลดพิเศษ รายการสินค้า ยอดก่อน/หลังส่วนลด VAT 7%, รวมเงิน; มีเงื่อนไขมัดจำ 60% / คงค้าง 40%, บัญชีโอนเงินที่ผู้ใช้ส่งมา และลายเซ็น จากนั้นกด **พิมพ์ / บันทึก PDF** (เลือก Save as PDF ในเบราว์เซอร์)
8. Dashboard เซลล์: แสดงข้อมูลที่บันทึก **ในเบราว์เซอร์เครื่องนั้น** แยกตามชื่อเซลล์ ทดลอง Export CSV สำหรับ Google Sheets

## สูตรที่เปิดใช้

**ม่านลอน / ม่านจีบ / ม่านตาไก่** ใช้ Pricing Engine ร่วมกันตามที่ผู้ใช้ยืนยัน ณ 27 ต.ค. 2569 รายละเอียดดู `FORMULA_RULES.md` โปรแกรมตรวจขนาดใช้ได้หลังหักเผื่อเย็บ 0.30 เมตร กรณีสูตรหน้ากว้างกับเย็บกลับ และแสดงคำเตือนรอยต่อของสูตรหน้าแคบ

### เอกสารใบเสนอราคา

- ตัวอย่างรูปแบบได้รับแรงบันดาลใจจากตัวอย่าง PROFACE ที่ผู้ใช้ส่งมา แต่ **โลโก้ใน Demo เป็น wordmark จำลอง** (ไม่มีไฟล์ CI vector ต้นฉบับ)
- ข้อมูลบริษัท บัญชีธนาคาร และเงื่อนไขชำระเงินในเอกสารนำมาจากภาพตัวอย่างที่ผู้ใช้ส่งมา ควรให้ฝ่ายบัญชีตรวจสอบความถูกต้องก่อนใช้ส่งลูกค้าจริง
- ราคาสินค้าในใบเสนอราคา = ราคาขายต่อชุดที่ระบบปัดหลักร้อยตามสูตร ตามด้วยส่วนลดพิเศษระดับเอกสาร และ VAT 7%; เงินมัดจำ 60% และคงค้าง 40% คิดจากยอดสุทธิรวม VAT
- ปุ่มพิมพ์ใช้ระบบ Print/Save PDF ในเบราว์เซอร์ ไม่ได้ส่งเอกสารให้ลูกค้าหรืออัปโหลด PDF ไปเซิร์ฟเวอร์

## ข้อจำกัด

**V5 เป็น Demo แบบ local-only**: ยังไม่มี Login, Backend หรือ Google Sheets Sync จริง ข้อมูล/รูปเก็บใน localStorage ของเบราว์เซอร์และอาจสูญหาย/เต็มได้ ไม่มีการส่งข้อมูลขึ้นเว็บหรือข้ามอุปกรณ์ CSV สำหรับนำเข้าชีตยังไม่ใช่การซิงก์อัตโนมัติ และไฟล์ CSV ไม่มีภาพแนบ (มีจำนวนรูป)

งานจัดซื้อ การคำนวณจำนวนผ้าสำหรับสั่งซื้อ/ตัดเย็บจริง ยัง **ไม่ได้พัฒนา** และจำนวนชิ้นที่ใช้เพื่อคำนวณราคาไม่ใช่จำนวนผ้าสั่งซื้อ จนกว่าจะได้รับสูตรจัดซื้อจริง กฎราคาเย็บกลับในเดโมยังยึดผล Excel ตัวอย่างที่ให้ค่าเท่ากับหน้าแคบ จึงควรตรวจเงื่อนไขก่อนนำไปเสนอราคาจริง

ล้างข้อมูลทั้งหมดได้ที่ Dashboard; V5 ใช้คีย์ localStorage แยกจาก V4 เพื่อให้เริ่มว่างทันที
