# PROFACE Workflow Studio — Interactive Demo

ตัวอย่างเว็บไซต์ Static Front End สำหรับ GitHub Pages และใช้งานบนมือถือ

## วิธีเปิด
เปิด `index.html` ในเว็บเบราว์เซอร์ หรืออัปโหลดโฟลเดอร์ทั้งหมดใน Repository ของ GitHub แล้วเปิดใช้งาน GitHub Pages

## ฟีเจอร์ที่ลองใช้งานได้
1. หน้า Dashboard พร้อม Flow และตัวอย่างรายการจริง 5 รายการที่ **ทำราคาได้ 24,900 บาทก่อน VAT** ตามชีตสอง
2. หน้าวัดหน้างาน: สร้างหนึ่งชุดหรือสร้างหลายชุดที่ใช้ความสูงเดียวกัน แต่แยกเป็นคนละชุดหลังบันทึก; แก้ไข/ลบ; แนบภาพหลายรูปแยกตามชุด
3. หน้า Admin Pricing: ปรับหน้าผ้า, ราคาราง และราคาผ้า; ระบบคำนวณสูตรม่านลอนจากไฟล์ที่ส่งให้
4. หน้าตรวจรายการและอนุมัติ, หน้าพรีวิวใบสั่งงาน, Print/Save PDF, ดาวน์โหลดไฟล์ TXT และ JSON
5. ข้อมูลส่วนใหญ่เก็บใน `localStorage` ของเบราว์เซอร์เท่านั้น

## สูตรที่เปิดใช้งานใน Demo (เฉพาะม่านลอน)
ถอดจาก `ชมพู่ 12.10.2026` ในไฟล์ Excel ตัวอย่าง, แถว 8, 11, 14:

- `effectiveWidth = MAX(width,1)`
- `panels = ROUNDUP(((effectiveWidth * 2.4)+1) / fabricWidth,0)`
- `quantity = ((height+1.8)*panels)*1.2`
- `rawPrice = (quantity*fabricRate) + (width*trackRate)`
- `salePrice = ROUND(rawPrice,-2)`

ตัวอย่าง: 1.24 × 2.645, หน้าผ้า 3.01, ราง 800, ราคาผ้า 295 → ชิ้น 2, quantity 10.668, price 4,139.06 → ขาย 4,100 บาท

ราคาผ้าที่กรอกเป็นค่าในช่อง **ราคาตั้ง-50% แล้ว** ไม่หัก 50% ซ้ำ

**สำคัญ:** quantity คือปริมาณที่ใช้ *คิดราคา* ในชีตตัวอย่าง ไม่รับรองว่าเท่ากับจำนวนผ้าที่ต้องซื้อจากฝ่ายจัดซื้อ

## ขอบเขตที่ยังไม่ได้ทำ
- ไม่มีระบบ Login, API Backend, Google Sheets sync, Google Drive/Firebase รูปถ่าย, สิทธิ์จริง หรือระบบหลายผู้ใช้
- ข้อมูลและรูปเก็บในเครื่องที่เปิดเว็บและมีข้อจำกัดด้านพื้นที่จัดเก็บ; ไม่เหมาะกับข้อมูลลูกค้าจริง
- ประเภทม่านอื่นยังไม่ได้เปิดสูตร; ราคาพิเศษและสินค้าขั้นต่ำยังไม่ได้ครอบคลุมทั้งหมด
- ใบสั่งงานเป็นตัวอย่างข้อมูลส่งต่อ ไม่ใช่ใบสั่งซื้อผ้าจริง
- ต้องทดสอบสูตรและเงื่อนไขสินค้าทุกประเภทเทียบกับ Excel ก่อนขึ้นระบบจริง
