# PROFACE Workflow Studio V6 — Blank Start

เว็บทดลองใช้งาน Workflow ของฝ่ายขายและแอดมิน PROFACE บนคอมพิวเตอร์และมือถือ ต่อเนื่องจาก V5 และเพิ่มสูตรพื้นที่ม่านม้วน/มู่ลี่ไม้, ปุ่มคัดลอกชุดวัด และกรณีต่อผ้าหน้ากว้าง

## เปิดใช้งาน

1. แตกไฟล์ ZIP ทั้งโฟลเดอร์ จากนั้นเปิด `index.html` ด้วยเบราว์เซอร์ (หรือเผยแพร่ไฟล์ `index.html`, `app.js`, `styles.css`, `quote.css` บน GitHub Pages)
2. เปิดครั้งแรกจะไม่มีลูกค้า/งาน/ราคา/ภาพตัวอย่าง V6 ใช้คีย์ LocalStorage แยกจาก V5
3. สร้างโปรเจกต์ ระบุ Sales Owner จาก S'Beam, S'Tong, S'Gun, S'Bank, Showroom
4. เซลล์กรอกขนาดรายจุดและแนบรูป หน้ารายการมีปุ่ม **คัดลอก** เพื่อนำขนาด/ห้อง/จุด/รูปเดิมไปใช้สร้างรายการผ้าทึบหรือผ้าโปร่งเพิ่มเติม (ไม่คัดลอกราคา)
5. แอดมินกรอกราคาด้วยตัวเองใน **Pricing** — ไม่มีราคาสินค้าค่าเริ่มต้น หรือดึงราคาตามรหัสสินค้าโดยอัตโนมัติ
6. ไปตรวจสอบรายการ/รูปและราคา → ยืนยัน → ใบสั่งงาน → ใบเสนอราคา → เลือก Print / Save as PDF
7. Dashboard แยกรายชื่อเซลล์โดยกรองข้อมูลที่บันทึกในเบราว์เซอร์; Export CSV เพื่อทดลองนำไปใช้กับ Sheets ได้

## Pricing Engine

- **ม่านจีบ, ม่านลอน, ม่านตาไก่** ใช้สามวิธี: หน้ากว้าง, หน้าแคบ, เย็บกลับหน้าผ้า ระบบต้องได้หน้าผ้า, ราคาราง, ราคาตั้ง -50% จากแอดมิน
- **หน้ากว้างที่เกินหน้าผ้าใช้ได้** (หน้าผ้า − 0.30 เมตร) จะขึ้นเตือน ถ้าแอดมินยืนยันการต่อผ้าด้วย Checkbox จึงคิดราคาโดยใช้สูตรจำนวนชิ้นแบบต่อผ้าที่เทียบกับ Excel สำเร็จ และระบุคำเตือนให้แจ้งลูกค้า
- **เย็บกลับหน้าผ้า** ตรวจความสูง ≤ หน้าผ้า − 0.30 เมตร
- **ม่านม้วน, มู่ลี่ไม้** เลือกวิธีคิดพื้นที่ `ตารางหลา ×1.2` หรือ `ตารางเมตร ×1.0` โดยแอดมินกรอกราคาต่อหน่วยเอง ค่าเริ่มต้นเป็นช่องว่าง
- การปัดราคาขายใช้ปัดใกล้หลักร้อยตามสูตร Excel; VAT 7% แสดงแยกจากราคาก่อน VAT

รายละเอียดสูตรและชุดตัวเลขทดสอบ: `FORMULA_RULES.md`

## QA ตัวอย่างที่ตรวจบนเบราว์เซอร์

- ม่านลอน 3.34 × 3.08 หน้าผ้า 3.00 ต่อผ้า ราง 800 ผ้า 350: **10,900 บาท**
- ผ้าโปร่งคัดลอกจุดเดียวกัน หน้าผ้า 2.95 ต่อผ้า ราง 800 ผ้า 145: **6,100 บาท**
- ม่านม้วน 1.26 × 2.95 ราคา/หน่วย 600 ตร.หลา: **2,700 บาท**
- มู่ลี่ไม้ 0.99 × 2.30 ราคา/หน่วย 1,500 ตร.หลา: **4,100 บาท**
- สร้างงาน 2 โปรเจกต์คนละเซลล์ แล้วตรวจ Dashboard และการสร้างใบเสนอราคา A4 ผ่าน

## ข้อจำกัดและความปลอดภัย

**V6 เป็น Demo local-only ไม่ใช่ระบบ Production** ไม่มี Login/Backend และยัง **ไม่เชื่อม Google Sheets อัตโนมัติ** ไม่มีการซิงก์ข้ามเครื่อง CSV เป็นเพียงตัวช่วยนำเข้าข้อมูลโดยคน รูปเก็บใน localStorage ของเบราว์เซอร์และอาจหาย/เต็มได้ กรุณาอย่าใช้เก็บข้อมูลลูกค้าจริงที่ต้องรักษาความปลอดภัยบนเครื่องสาธารณะ อย่านำเว็บ Demo ขึ้น GitHub Pages แล้วเข้าใจว่าเป็นเว็บปิดส่วนตัว

- ตัวเลขจำนวนชิ้นของสูตรต่อผ้าเป็น **จำนวนใช้คิดราคา** ไม่ใช่จำนวนตัดจริงหรือรายการสั่งซื้อ
- สูตรเย็บกลับหน้าผ้ายังคงใช้สูตรราคาตามชุดตัวอย่าง Excel ที่ให้ผลเท่ากับหน้าแคบ; ต้องตรวจเพิ่มเติมกับงานอื่นก่อนใช้จริง
- สูตรพื้นที่และการปัดราคาควรตรวจด้วยหลายขนาดและเงื่อนไขสินค้าก่อนนำเสนอราคาลูกค้าจริง
- สูตรจัดซื้อและงานช่างเย็บ **ยังไม่ได้พัฒนา**
- ใบเสนอราคาใช้ wordmark จำลอง และข้อมูลบริษัท/บัญชี/ข้อกำหนดตามตัวอย่างภาพที่ผู้ใช้ส่งมา **ต้องให้ฝ่ายบัญชียืนยันก่อนใช้งานจริง**
