# PROFACE Workflow Studio — Blank Start Demo V2

**เปิดครั้งแรกด้วยฐานข้อมูลว่าง** ไม่มีโปรเจกต์ ลูกค้า ชุดม่าน รูปภาพ หรือราคาเริ่มต้น และไม่โหลดข้อมูลตัวอย่างจาก Demo รุ่นก่อน

## เริ่มทดลอง
1. เปิดไฟล์ `index.html` หรืออัปโหลด `index.html`, `app.js`, `styles.css` ไปยัง GitHub Pages
2. หน้า Dashboard กรอกชื่องานและข้อมูลลูกค้า จากนั้นกด **สร้างงานและเริ่มวัดหน้างาน**
3. ฝ่ายขายกรอกขนาดผ้าม่านแต่ละชุด พร้อมแนบรูปภาพ (โหมดหลายชุดที่ความสูงเท่ากันแยกเป็นคนละรายการ รูปของแต่ละชุดเพิ่มได้หลังบันทึก)
4. แอดมินเปิดทำราคา กรอกรหัสสินค้า / **หน้าผ้า / ราคาราง / ราคาตั้ง -50%** สำหรับแต่ละรายการ
5. ม่านลอนที่มีข้อมูลครบสามารถคำนวณด้วยสูตรที่ตรวจสอบจากไฟล์ Excel ได้ แล้วไปตรวจสอบรายการแนบภาพและยืนยัน
6. หลังยืนยันจึงเปิดพรีวิวใบสั่งงานและพิมพ์ PDF หรือดาวน์โหลดข้อความได้

ต้องการเริ่มใหม่: กลับหน้า **ภาพรวม** แล้วเลือก **ล้างข้อมูลทั้งหมดเพื่อเริ่มใหม่** (ลบข้อมูลรวมถึงรูปทดลองจากเบราว์เซอร์นี้)

## สูตรตัวอย่างที่เปิดใช้: เฉพาะม่านลอน / Wave
`effectiveWidth = MAX(width,1)`
`panels = ROUNDUP(((effectiveWidth*2.4)+1) / fabricWidth,0)`
`quantity = (height+1.8)*panels*1.2`
`rawPrice = quantity*fabricRate + width*trackRate`
`salePrice = ROUND(rawPrice,-2)`

**สำคัญ** ราคาผ้าที่กรอกคือค่าหลังลด 50% ที่ใช้ในสูตรแล้ว ไม่ลดซ้ำ หน่วยปริมาณคือปริมาณที่ใช้คำนวณราคา ไม่ใช่จำนวนผ้าสั่งซื้อ

## ข้อจำกัด
- ยัง **ไม่เชื่อม Google Sheets หรือ Backend** ไม่มีล็อกอินจริง ไม่รองรับการใช้งานพร้อมกันหลายเครื่อง
- ข้อมูลและรูปภาพเก็บใน `localStorage` ของเบราว์เซอร์ที่เปิดเว็บเท่านั้น ไม่เหมาะกับข้อมูลลูกค้าจริง และอาจหายเมื่อเคลียร์ข้อมูลเว็บ
- ตอนนี้รองรับการเปิดงานทีละโปรเจกต์ต่อเบราว์เซอร์ รุ่นนี้ตั้งใจใช้ทดสอบ Workflow ตั้งแต่ศูนย์
- ยังไม่ครอบคลุมกฎราคา/ต้นทุนทุกกรณีของม่านลอน และไม่เปิดสูตรสินค้าชนิดอื่นหรือสูตรฝ่ายจัดซื้อ
- การยืนยันต้องมีรูปแนบอย่างน้อยหนึ่งรูป **ทุกชุด** และคำนวณราคาได้ทุกชุด
